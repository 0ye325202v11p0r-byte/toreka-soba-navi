## カードデータの収録範囲（2026-09-11時点、3,270件）

2つのデータソースを組み合わせている：

1. **onepiece-card-atari.jp**（844件、`data_quality: 'real'`）— 複数店舗の平均価格を毎日追跡している価格トラッカーサイト。個別ページを持つのは「特別収録ボックス」（ワンピースカード ザベスト等）や各セットのSP/パラレル等のチェイスカードのみ。`sitemap-cards.xml`の894件（全23セット）を精査済みで、**このサイト単独ではこれ以上増やせない状態**（サイト自体の設計上の上限）。
2. **yuyu-tei.jp（遊々亭）**（2,426件、`data_quality: 'partial'`）— 実店舗の現在の店頭販売価格。上記サイトが対象外としているノーマルレアリティ（C/UC/R/SR/Lのパラレルなし版）を、OP01〜OP17の主要17セット・ST01〜ST36の全スターターデッキ・EB01〜EB04の全エクストラブースターから網羅的に取得（うち3件は、印刷バリエーション混同で長らく未ソースの手動参考値だったc9/c500/c503を、遊々亭の「特別パラレル」商品ページ発見により実測ソース付きに格上げしたもの）。ただし**1店舗・1時点の価格のみ**（複数店舗平均でも、時系列の実測履歴でもない）。統計値（30日/90日平均・判定）は算出せず、現在価格のみを参考値として表示。画像・記事文章は一切保存せず、価格数値のみを取得している。

いずれのソースも将来的にサイト構造が変わればスクレイパーが壊れる可能性がある。`migration/expand_catalog.mjs`（ソース1）と`migration/scrape_yuyutei.mjs`（ソース2）が現在の実装。

### 遊々亭ソースの法務リスクについて（2026-09-12、ユーザー判断済み）

遊々亭の`robots.txt`は一般クローラーを明示的にブロックしておらず、サイトルール（`/info/rule`）も「画像・コンテンツの無断転載禁止」としか書いていない（自動アクセス自体を禁止する条文はない）ことは確認した。**これは「明示的に禁止されていない」という消極的な事実確認であり、法務的なお墨付きではない**という限界も含めて、以下はユーザー本人が把握した上での判断。

- 個別ページのWebFetchで数枚だけ参照した1つ目のデータソース（onepiece-card-atari.jp、ClaudeBot等のAIクローラーをrobots.txtで明示的に許可）とは性質が異なり、遊々亭は**実店舗の在庫連動の販売価格を、40セット・2,426件という商品カタログのほぼ全域にわたって体系的に収集**している。個別の事実の引用というより、相手の商品カタログを大規模に複製したとも評価されうる規模感であり、日本法における不正競争防止法・利用規約違反（債務不履行/不法行為）のリスクをゼロと言い切れる根拠はない（この事実関係の評価自体は変わっていない）。
- **ユーザー判断（2026-09-12）：** 個人規模でのこの種のデータ収集について、実際に摘発・法的措置に至った事例がこれまで確認できないレベルのリスクであり、許容範囲と判断（本人の言葉を借りれば「信号無視をしても刑務所には入らない」程度の実務上のリスク水準という評価）。Claude（このプロジェクトのAI実装担当）は法律専門家ではなく、この判断の法的な正しさを保証するものではない——**これはユーザー自身のリスク受容の意思決定であり、Claudeによる法務助言ではない**、という位置付けを明記しておく。
- ~~相手が把握して停止要求をしてきた場合の対応方針が未整備~~ → 2026-09-12、`app_settings`テーブルによる緊急停止スイッチを実装（`src/lib/appSettings.ts`）。Supabase SQL Editorで`update public.app_settings set value='false'::jsonb where key='yuyutei_source_enabled'`を実行するだけで、再デプロイ不要・即座に①`refresh-yuyutei-prices`がyuyu-tei.jpへのリクエストを一切送らなくなり、②相場一覧・カード詳細から遊々亭ソースのカードが非表示（詳細ページは404）になる。手順の詳細は`migration/README.md`「🛑 緊急停止スイッチ」参照。**ただしテーブル自体の作成は上記の日次自動追跡と同様、本番未反映**（Supabase SQL Editorでの実行が必要）。

## データの正確性について

店頭平均価格と個人間フリマ（メルカリ等）の実売価格には差がある。価格データは複数のカードショップの平均価格であり、フリマ相場とは別の指標。UIにもその旨を明記している。

データ移行・拡充作業を通じて、合計4件の重大なデータ誤り（c9, c2, c500, c503 — いずれも印刷バリエーションの取り違え）を発見・修正済み。同種のリスクがある「品番が特殊な34件」は全件、実際のページと照合して検証済み（詳細はgitのコミット履歴参照、特に `04ff55c` と `7baef21`）。c500/c503は2026-09-11のカタログ拡充作業中に統計的異常検知で新たに発見し、WebSearchで同系統カードに複数の実在バリエーション（白文字版と赤箔仕様のコラボ版）があることを確認した上で修正した（詳細は該当コミット参照）。その後、c9/c500/c503とも遊々亭の「特別パラレル」という別商品ページ（白文字版とは異なるproduct ID）を発見し、未ソースの手動参考値（`data_quality: 'flat'`）から実測ソース付き（`data_quality: 'partial'`）に格上げ済み。
