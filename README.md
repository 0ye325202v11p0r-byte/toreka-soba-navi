## カードデータの収録範囲（2026-09-11時点、2,622件）

2つのデータソースを組み合わせている：

1. **onepiece-card-atari.jp**（846件、`data_quality: 'real'`）— 複数店舗の平均価格を毎日追跡している価格トラッカーサイト。個別ページを持つのは「特別収録ボックス」（ワンピースカード ザベスト等）や各セットのSP/パラレル等のチェイスカードのみ。`sitemap-cards.xml`の894件（全23セット）を精査済みで、**このサイト単独ではこれ以上増やせない状態**（サイト自体の設計上の上限）。
2. **yuyu-tei.jp（遊々亭）**（1,776件、`data_quality: 'partial'`）— 実店舗の現在の店頭販売価格。上記サイトが対象外としているノーマルレアリティ（C/UC/R/SR/Lのパラレルなし版）を、OP01〜OP17の主要17セットから網羅的に取得。ただし**1店舗・1時点の価格のみ**（複数店舗平均でも、時系列の実測履歴でもない）。統計値（30日/90日平均・判定）は算出せず、現在価格のみを参考値として表示。robots.txtは一般クローラーを明示的にブロックしておらず、サイトルール（`/info/rule`）は画像・コンテンツの無断転載を禁止しているが自動アクセス自体は禁止していないことを確認した上で、価格数値のみを取得（画像・記事文章は一切保存していない）。

いずれのソースも将来的にサイト構造が変わればスクレイパーが壊れる可能性がある。`migration/expand_catalog.mjs`（ソース1）と`migration/scrape_yuyutei.mjs`（ソース2）が現在の実装。

## データの正確性について

店頭平均価格と個人間フリマ（メルカリ等）の実売価格には差がある。価格データは複数のカードショップの平均価格であり、フリマ相場とは別の指標。UIにもその旨を明記している。

データ移行・拡充作業を通じて、合計4件の重大なデータ誤り（c9, c2, c500, c503 — いずれも印刷バリエーションの取り違え）を発見・修正済み。同種のリスクがある「品番が特殊な34件」は全件、実際のページと照合して検証済み（詳細はgitのコミット履歴参照、特に `04ff55c` と `7baef21`）。c500/c503は2026-09-11のカタログ拡充作業中に統計的異常検知で新たに発見し、WebSearchで同系統カードに複数の実在バリエーション（白文字版と赤箔仕様のコラボ版）があることを確認した上で修正した（詳細は該当コミット参照）。
